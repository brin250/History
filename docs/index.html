    Sync across devices

    Keep your progress in the cloud so your phone, tablet and computer all share it. It is stored as a private file on your GitHub account. Do this once on each device:
    1. Sign in to GitHub and make a token that can only read and write gists (link below). Set the expiry to "No expiration" or after your exams, then copy the token.
    2. Paste it here and tap Connect. Use the same token on every device.
    Make a gist-only token on GitHub ↗ Already connected on another device? Copy its link code (Progress → Sync across devices) and paste it here instead of a token.

    Back up or move your progress

    Your progress saves automatically on this phone after every card. To keep a copy you can restore if the app is deleted or you change phone, save a backup file (it goes to Files / Downloads) or copy the backup code into Notes.
